# minicode Landing Page Design Brief

## Objective
Create a premium, production-grade landing page for minicode — an ultra-lightweight autonomous AI coding agent built for developers.

## Aesthetic Direction
**Theme**: Dark developer tooling + restrained cyber aesthetic
- Deep space blacks with subtle grid patterns
- Neon accent glows (cyan/teal primary, magenta secondary)
- Glassmorphism cards with subtle borders
- Futuristic AI infrastructure feel

## Color Palette
```css
--bg-primary: #030508;        /* Deep space black */
--bg-secondary: #0a1018;     /* Slightly lighter panels */
--bg-card: #0d1520;           /* Card backgrounds */
--accent-cyan: #00d4ff;       /* Primary accent - tech feel */
--accent-magenta: #ff00aa;    /* Secondary accent */
--accent-green: #00ff88;      /* Success/verification */
--text-primary: #ffffff;      /* Headings */
--text-secondary: #8892a0;    /* Body text */
```

## Content Structure (14 Sections)
1. Hero with interactive terminal preview
2. Philosophy: "Evidence before assertions"

5. Multi-Agent Council
6. Code Intelligence
7. Security by Design
8. Browser Automation

11. Comparison Table

14. Final CTA
